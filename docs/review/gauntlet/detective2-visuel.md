## Begrænsninger
Dev-serveren leverer uminificeret/ukomprimeret CSS+JS, så lokale 3G-tal (FCP 3,8-5,3 s) overdriver; live-tal (gzip) er medtaget. Indlogget tilstand med data (dashboardets annonceliste, statkort, krav) er ikke set (ingen konti/skrivning). `annonce.html?id=1` viser "Annoncen findes ikke" (ingen testdata). Pixelsampling er median/90. percentil i tekstens bounding box; værdier ved ca. 2,4-2,8:1 på store hero-titler er worst-case, ikke gennemsnit. Ingen build/generatorer kørt i hovedmappen; hovedmappen urørt.
