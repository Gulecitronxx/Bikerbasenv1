# Detective: SEO og linkkvalitet (Bikerbasen)

Undersøgt 2026-10-15, branch gauntlet/master, kun læsning. Ingen produktionskode ændret, crawleren ikke kørt, intet sendt mod tredjepartssites.
Live-målinger: kun bikerbasen.dk selv (HEAD/GET, ca. 1 request/sek., i alt ca. 60 requests). Lokal server http://localhost:8700 til dækningsmåling (eksterne requests blokeret).
Scripts ligger i scratch-mappen, ikke i repoet. Rå-måling for alle 63 rod-sider: se "Metode".

Skala: sev P0 (tab af indeks/falsk påstand) til P3 (kosmetisk). Type: **verificeret** = målt/set i kode eller live. **hypotese** = plausibelt, kræver Search Console eller render-test. **forbedring** = ikke en fejl, men vækstmulighed.
Indsats: XS under 1 time, S under en halv dag, M 1-2 dage, L over 2 dage.
Sorteret efter forventet organisk effekt pr. indsats (højest øverst).
