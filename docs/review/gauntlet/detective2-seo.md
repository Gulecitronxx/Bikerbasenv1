## Verificeret OK

- **Sitemap:** 56 URL'er, alle 200, ingen redirects, ingen noindex-sider, alle selv-canonical (canonical = sitemap-URL på 56/56). Lokal og live sitemap afviger kun i lastmod.
- **Title/description:** længder 30-60 / 80-153 tegn, ingen dubletter af title, description eller H1 på tværs af 56 sider; præcis én H1 pr. side; titel og og:title/og:url matcher; og:image findes (`og-image.png` 178 KB, 55 sider; annonceside bruger egen foto). Ingen hreflang (ét sprog), ingen behov.
- **JSON-LD:** alle blokke parser. FAQPage: hvert spørgsmål og svar står synligt på siden (0 afvigelser på 28 sider). Ingen AggregateRating/Review; Product kun på egne annoncer med pris, valuta, availability. Article har dato, forfatter-org, headline. Ingen falske påstande fundet bortset fra T-006 (formulering).
- **robots.txt:** `Allow: /` + Sitemap, 200, max-age 4 t. Noindex-sider er crawlbare, så noindex kan ses.
- **Redirects:** http→https 301, www→apex 301 (også for dybe stier).
- **404:** rigtig 404-status på dybe, ukendte, store-bogstav-URL'er; 404-siden har `noindex, follow` og virkende stilark/links.
- **Parametre/facetter:** `soegning.html?…` og `?page=` canonical til `/soegning`; nul træf giver `noindex` (`js/search.js:1860`); facet-sider i sitemap er statiske og egen-canonical.
- **Bortfaldne annoncer:** `annonce.html?id=` er nu statisk noindex (soft-404 uden risiko for indeks); egne annoncesider fjernes fra build og sitemap. Forbehold: ekstern annonces "borte" afspejles først ved næste deploy (S-004, kendt).
- **Intern linkgraf:** 0 forældreløse indekserbare sider (kun 404, afmeld, dashboard, forhandler, bevidst); alle sitemap-sider er 1 klik fra forsiden (header/footer); indgående links: mc-/by-/model-sider 3-16, budget 36, kørekort 80, guides 12-31.
- **Core Web Vitals (lokalt, throttlet):** mobil FCP/LCP 1,1-1,9 s, LCP er lokal WebP (hero-800 34 KB) med preload+`fetchpriority`; desktop LCP 0,3-0,4 s. CSS 2 filer, 28 KB over nettet (gzip), JS 50-74 KB (gzip) pr. side, fonte 67 KB preloadede. Ingen vandret overflow (0 px på alle 20 målinger). Kortbilleder har `aspect-ratio` (ingen CLS fra billeder).
- **Headers (live):** HSTS (preload), X-Frame-Options DENY, CSP (`frame-ancestors` som header, resten som meta), nosniff, Referrer-Policy, Permissions-Policy, COOP. Caching: HTML 10 min, billeder/robots/sitemap 4 t (sitemap 10 min), CSS/JS versioneret med hash.
- **Juridisk:** ingen fund i denne runde berører CLAUDE.md-reglerne; foreslåede kilde-/forhandlersider (T-011) kræver kildens samtykke og ejerens accept.
- **Guideindhold:** aldersgrænser i A2-guiden (A1 18, A2 20, A 24/22) stemmer med borger.dk's side om motorcykelkørekort.
