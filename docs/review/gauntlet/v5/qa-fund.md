## Hvad der VIRKER (verificeret)
- Chromium 151, Chrome 155, Edge 155 på live og lokal build: 0 konsolfejl, 0 sidefejl, 0 4xx fra egne filer, intet vandret overflow, ét h1 pr. side, ingen brudte egne billeder, fonte indlæst, cookie-dialog (vises, `:modal`, "Kun nødvendige" lukker, huskes, siden klikbar), søgning (fritekst, mærkevælger, nulstil) og annonceside.
- Chrome/Edge/Chromium giver ens layout-fingeraftryk (ingen forskel >2 % i højde, header eller skrift).
- CSS-funktionerne `:has`, `@container`, `color-mix`, `dvh` degraderer pænt: intet vandret overflow, ingen usynlig tekst, ingen konsolfejl i simuleringen (44 målinger/variant, kontrol = 0 forskelle).
- Ingen vagtliste-funktion (nesting, `@scope`, anchor, popover, `toSorted`, `structuredClone` ...) er i brug; gulvet er Chrome 111 / Safari 16.4 / Firefox 121.
- Sidevægt: js/data.js 44,8 kB gzip; største side (annonce) 390 kB; alt inden for budget.
- Ingen skrivning mod Supabase forsøgt (v5-tjekkene afviser og tæller ikke-GET; 0).
